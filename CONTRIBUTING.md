# Contributing

This framework started as a personal practice tool and is shared in case it's useful to others assessing legacy-to-cloud migrations under real-world budget and timeline constraints.

## Ways to contribute

- **Scenario walkthroughs:** if you've applied this methodology (or something similar) and can share a sanitized, generalized version of the outcome, a pull request to `/scenarios` is welcome. Please keep scenarios free of identifying client details — composite/illustrative examples only.
- **Platform mapping corrections:** if a service equivalent in `docs/platform-notes.md` is outdated or wrong, please open an issue or PR.
- **Scoring rubric feedback:** the default weights reflect typical small/mid-size business migrations. If you've found different weights work better for a specific industry or context, open an issue to discuss before submitting a PR — this is the part of the framework most likely to need ongoing refinement.

## What this repo is not

This is a methodology and template repository, not a software product. There's no roadmap toward a SaaS tool or commercial offering — issues asking for that kind of feature will likely be closed, not because it's a bad idea, but because it's outside the scope of what this repo is trying to be.
